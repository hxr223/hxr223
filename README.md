# 你好，我是老黄 👋

**AI Agent 工具开发者 · AI coding tools & practical agent workflows**

我在开发让 AI 完成实际工作的工具：从终端编程助手，到把 AI 设计图变成可编辑文件的 Agent Skills。

## 代表作品

### [laoHuangCode](https://github.com/hxr223/laoHuangCode)

运行在终端里的开源 AI 编程助手。用自然语言描述任务，让 Agent 阅读代码、修改文件和执行命令。

- 多供应商模型接入、交互式终端界面与会话管理。
- MCP 集成和动态工具搜索。
- 提供独立安装器与 npm 安装方式。

[开始使用](https://github.com/hxr223/laoHuangCode#安装) · [版本发布](https://github.com/hxr223/laoHuangCode/releases)

### [AI Image To Vector Redesign](https://github.com/hxr223/ai-image-to-vector-redesign)

把 AI 生成的设计图重建为可编辑 SVG、可审核 PDF 和高清 PNG 的 Agent Skill。

- 重新排版文字与矢量结构，保留复杂图像资产。
- 包含海报、长图和产品宣传图的重建案例。
- 提供导出脚本、细节对比和 QA 检查流程。

[查看效果案例](https://github.com/hxr223/ai-image-to-vector-redesign#效果案例) · [开始使用](https://github.com/hxr223/ai-image-to-vector-redesign#快速开始)
